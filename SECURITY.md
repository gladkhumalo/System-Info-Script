# Security policy

## Reporting a vulnerability

Please do not disclose a security issue in a public GitHub issue. Use GitHub's private vulnerability reporting feature when it is available, or contact the repository owner through the profile links.

Do not attach generated system-information reports to public issues. Reports can contain computer names, IP addresses, operating-system details, and storage information.

## Supported version

Security fixes are applied to the latest version on the `main` branch.
